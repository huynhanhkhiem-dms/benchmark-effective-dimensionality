# Benchmark Effective Dimensionality Under Algorithm-Portfolio Variation

Reproducibility materials for the manuscript **“Benchmark Effective Dimensionality Under Algorithm-Portfolio Variation”** by Huynh Anh Khiem (ORCID: 0009-0007-7210-174X).

This repository contains the analysis code, analysis-ready derived benchmark outputs, finite-portfolio reference results, provenance-link audit inputs, and the frozen CC18 K=84 protocol used to reproduce the numerical diagnostics reported in the manuscript.

## Repository structure

- `analysis/reproduce_results.py` — reproduces the reported analysis layer.
- `analysis/requirements.txt` — minimal Python dependencies.
- `data/` — analysis-ready score matrices and derived reference outputs.
- `protocol/FROZEN_PROTOCOL_CC18_K84.json` — frozen CC18 K=84 protocol.
- `verified_reported_results.json` — machine-readable output generated by the reproduction script.
- `SHA256.txt` — checksums for repository data, code, and protocol files.

## Reproduction

```bash
python -m pip install -r analysis/requirements.txt
python analysis/reproduce_results.py
```

The script writes `verified_reported_results.json` at the repository root.

## Data provenance

The underlying UCI and OpenML benchmark datasets are public and are cited in the manuscript. Raw source datasets are not redistributed here. The files in `data/` are derived, analysis-ready outputs sufficient to reproduce the reported effective-dimensionality, portfolio-stability, family-level, leave-one-family-out, metric-sensitivity, held-out subspace-reconstruction, and provenance-response diagnostics.

The repository does not refit every model from the original raw datasets; it reproduces the manuscript analysis from the saved derived evaluation outputs.
